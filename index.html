    03 / WORKING MODE

    Ma façon d’aborder un problème

    1. 01Cartographier

      Comprendre les flux, les contraintes et les interfaces avant de coder.

    2. 02Modéliser

      Choisir des structures de données et des responsabilités qui rendent le problème lisible.

    3. 03Construire

      Avancer par incréments testables, avec des contrats explicites entre les composants.

    4. 04Casser

      Tester les limites : entrées invalides, concurrence, erreurs réseau, mémoire et reprise.

    5. 05Expliquer

      Documenter les choix pour qu’une autre personne puisse reprendre le système.
